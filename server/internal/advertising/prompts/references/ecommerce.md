# 从原始电商 prompt 提炼的写法

## 观察依据与真正要学习的东西

本技能来自一组广告生成任务的文本观察。以下编号仅对应整理时的样本顺序，用于说明归纳依据；使用技能不需要原始数据，也不表示已检验成片效果。

| 原样本 | 实际写法 | 可复用机制 |
|---|---|---|
| #2 萝卜干 | 一整段连续描述，盛盘→酱汁微距→配粥→夹馒头→配饭→入口→分屏包装，每个镜头紧接旁白 | 用食物色泽、纹理、食用动作承担卖点，台词像推荐吃法；无需硬套统一字段 |
| #4 仓库口播 | 绑定人物/包装，写仓库、篮子、音色，按时间码安排持货、指产品、邀请动作及促销台词 | 商品、演员、场地有明确外观；“福利等到了”的话术与推销表演同时发生 |
| #55–57 护发喷雾 | 使用动作、人物吐槽、手部微距、产品特写、人物分享来回切换；同一个声音在画内与画外延续 | 一条广告的开头、中段、结尾分别生成；每段不必重介绍和重CTA |
| #63 双人反转 | 质问→惊讶→拿出商品→解释→关系缓和，分角色音色、左右站位和逐镜对白 | 用角色关系推动商品露出，而不是所有演员只举产品念卖点 |
| #86 超现实桥段 | 追逐→遇险→夸张商品道具救场→旁人反应→短句收尾 | 商品作为剧情道具，服务反转与记忆点；不代表所有广告都要现实测评 |
| #90/#95 八镜头广告 | 素材职责、人物商品、声音、SC时间轴、约束；重复回到同一口播场景，同一句话跨切镜 | 锁剪辑顺序，明确哪些镜头对口型、哪些延续画外音，宫格不进入成片 |
| #100/#104 桌面与讲解 | 手持产品/包装特写与人物讲解交替，一段完整讲话贯穿 | 产品镜头承接解说，展示和口播可以不逐字对应同一个动作 |
| #123 单人推销 | 从产品未入画开始，举至胸前，托底转标签，再配手势说价格，最后持瓶停稳 | 动作与台词重音绑定，明确产品从哪里来、谁拿着和段尾如何继承 |
| #144 宠物测评 | 整体风格/角色/情绪曲线→分段场景与动作→近景/特写→每段口播 | 每段既承担内容又承担情绪：场景引入、比较、使用、细节、收束 |

这些样本共同点是“把广告演出来”：开场怎么抓人、哪句用什么神态说、何时切商品、产品以什么状态出现、声音如何继续。它们没有统一的“商品介绍→口播稿→三镜头说明片”流程。

原稿也有错误：短时长塞入过量台词；换产品但旧功效/用法没换；“固定机位”与移动指令冲突；说禁文字却又要求新文字图示；物品在两镜间无交代地消失。保留表达方式，修正这些执行矛盾，不把错误纳入默认规范。

## 写话术时保留什么

- 保留对观众说话的关系：“姐妹们”“你们看”“每次……”“尤其是……的”按品类和受众选择，不强迫每条用同一称呼。
- 保留情绪推进：吐槽→提出选择→演示→肯定；悬念→反应→揭示；食欲→口感→搭配。不能所有镜头都是“微笑、展示、很方便”。
- 保留口语句式和自然重复，避免擅自把已有“我早就把……换成……”改成“本产品采用……”的说明书表达。
- 商品介绍可以藏在推荐、演示、对话中；商品图还负责外观，不能因为没有独立“商品介绍”标题就重构整条广告。
- 新写推荐话术要以商品资料为边界。情绪和戏剧可以创作，真实回购、使用效果、官方优惠等经历或事实不能凭空补。

## 写画面时要具体到哪里

每个关键镜头至少写清：谁/什么、何处、景别和切换、主要动作、台词或声音。关键物理细节按场景添加：

- 食品：红油反光、酱汁附着、筷子夹取、掰开馒头、酱汁沾到面皮、入口咀嚼；选择适合真实商品的细节。
- 洗护：喷头朝向、按压次数、细雾落点、梳头路径、瓶体正面、液体与手部；不凭空加入不支持的使用方式。
- 主播：产品入画时机、左右手分工、视线从商品回镜头、重音处点头/摊掌、收势。
- 剧情：两人方位、谁提问、谁反应、谁从哪里取物、商品改变了什么事件。

不要强制所有广告做“演示证据”，参考原片中的陈列、反应镜头、人物口播和情绪插镜都可以保留。镜头应服务广告内容，不必每秒都推镜或挪动物件。

## 完整示例A：连续叙述式食品广告

以下示例均为重新编写的教学稿，不使用真实租户品牌或素材。假设用户确认：图片1是瓶装香辣萝卜干，口感脆，可配粥配饭；目标15秒食品种草。示例只给模型 prompt：

```text
以<图片1>为香辣萝卜干及瓶身包装的外观依据，保持萝卜干颜色、切块形态与包装一致。15秒，9:16竖屏，写实美食短视频，温暖侧光，深木色桌面，成年女声普通话，语气自然带食欲感，声音贯穿切镜。视频开篇，俯拍近景里一碗白粥放在桌面左侧，右侧蓝花瓷小盘盛着香辣萝卜干，一双筷子从右上方夹起一块，红油在侧光下发亮，旁白说{白粥太寡淡？配点香辣萝卜干。}。接着硬切微距，筷子轻转萝卜干，露出表面纹理与附着的酱汁，旁白继续{香辣又脆，}；声音不换人，画面随即切至双手掰开白馒头的近景，一只勺子将萝卜干放进馒头切口，酱汁轻沾面皮，旁白接上句{夹进馒头也够味。}。随后硬切俯拍，一勺萝卜干落在米饭边缘，红亮小菜与白米饭形成颜色对比，旁白说{配粥配饭，来一口。}。最后切到产品陈列近景：瓶装产品直立在小盘后方，标签朝向镜头，前景萝卜干清晰、后方白粥轻微虚化，镜头小幅推近后停住。保留筷子触盘和馒头掰开的轻微声音，不加抢占旁白的音乐。包装、食物形态与光线前后一致，不新增字幕、水印、标题字卡或乱码，产品已有文字可保留。
```

学习点：商品信息融在画面和口播中；连续叙述也能精准指定切镜，不必加一段说明书式介绍。切镜节奏要给台词和主要动作留下时间。

## 完整示例B：参考绑定＋口播/特写交替

假设用户提供图片1人物、图片2产品、图片3场景，并确认产品是无需冲洗、可喷于发中至发尾的护发喷雾；粉色半透明瓶身、白喷头。目标15秒，此次从零创作一个种草开头，允许后续接使用感片段。

```text
<图片1>只定义角色A的外貌、服装、发型、体型、妆容和配饰，不采用图中背景、动作、站位或构图；<图片2>为护发喷雾的外观依据，保持粉色半透明瓶身、白色喷头、标签与瓶身比例，不继承展示台与背景；<图片3>只定义梳妆区的固定空间、家具与光影，不采用图中人物、动作或机位。
真人写实竖屏短片，15秒，9:16，生活化好物分享。角色A独自站在梳妆台前面向镜头，初始右手持喷雾垂于腰侧，左手空出，梳妆台上不额外增加同款产品。角色A使用成年女声，音色清亮，语速中等偏快，像向朋友分享，普通话。画内口播与画外旁白始终为同一个声音。
镜头1[00:00–00:04]：固定机位中景，人物居中；角色A先轻抬眉看向镜头，左手挑起肩侧一缕发尾，右手将喷雾从腰侧举至胸前，瓶身正面朝向镜头，角色A说{出门前理头发，你们看这个喷雾。}；句末视线从瓶身回到镜头。
镜头2[00:04–00:09]：硬切侧面近景，画面聚焦肩侧头发和持瓶右手，面部不入画；左手托起发尾，右手将喷头朝向发中至发尾按压一次，细雾落向发丝，随后停止喷洒；画外角色A的声音说{喷在发中到发尾，再轻轻梳开，}；保留短促喷雾声，旁白不因切镜重说。
镜头3[00:09–00:13]：硬切回同一梳妆区中景，角色A右手持瓶收回胸前，左手手指沿刚喷过的发束轻梳一次后垂下，目光看向镜头，嘴角微扬；角色A接上句说{不用冲洗，就能接着做造型。}。
镜头4[00:13–00:15]：硬切产品近景，右手仍竖直握持喷雾，标签正面朝向镜头，梳妆区在后方虚化，不出现面部；同一声音以画外旁白说{就是这瓶。}，瓶身轻转正后停稳。
段尾产品被右手竖直持握于画面中央，喷头向上、标签正向，声音自然收住，作为种草片段结束。保持角色A、场景固定结构与产品外观一致；旁白镜头不生成说话口型；不新增字幕、水印、台标、标题字卡或乱码，商品包装已有文字除外。
```

学习点：前几镜有介绍，但通过“说一句＋做一件事＋切一个画面”完成；成片形态接近人物口播与产品插镜，不是独立产品说明。片段末尾不用硬补购买话术。

## 完整示例C：双人反转＋商品露出

假设用户提供图片1角色A、图片2角色B、图片3三格带盖桌面收纳盒；两人为成年室友，15秒，温暖写实生活短剧。商品用途仅为分类收纳。

```text
参考<图片1>定义角色A的静态外貌、发型和服装，参考<图片2>定义角色B的静态外貌、发型和服装，不继承人物卡背景与站位。<图片3>为三格带盖桌面收纳盒的外观依据，保持盒型、颜色、分格和盒盖一致。
9:16竖屏，15秒，生活化双人剧情广告。场景为明亮卧室梳妆台前，镜子在后方，右侧有绿植，柔和自然光。角色A站在画面左侧，角色B坐在画面右侧；闭盖收纳盒始终放在角色B前方桌面，其内部有发圈、回形针和小夹子，各占一格。角色A为清亮成年女声，情绪从着急转为意外；角色B为温和成年女声，语速自然，语气从从容解释转为轻松，普通话，两人的声线和发声主体分开。
镜头1[00:00–00:04]：固定机位双人中景，角色A身体微前倾，左手拨开桌边的一本杂志，抬眼看向角色B，眉头微皱，角色A说{我刚放这儿的发圈呢？}；角色B闭口，抬头看她，不跟随说话。
镜头2[00:04–00:08]：硬切桌面俯拍近景，角色B双手打开收纳盒，将盒盖放在盒体后方，三格内的不同物件清晰显露；随后从发圈所在格子取出一枚，画外角色B的声音说{在这儿，给你分开放好了。}；开盖与取物动作顺序清楚，保留轻微物件摩擦声。
镜头3[00:08–00:12]：硬切回双人中近景，角色B右手将刚取出的发圈递给角色A，角色A伸左手接住，表情从皱眉转为眉眼舒展，目光从发圈移向打开的盒子，角色A说{难怪，找起来不用翻一桌了。}；角色B微笑听着，不同时说话。
镜头4[00:12–00:15]：硬切产品俯拍近景，打开的三格收纳盒占据主体，发圈格比之前少一枚，其余物件不变，盒盖仍在后方；角色B一只手轻扶盒边，画外角色B的声音说{小东西，各有各的位置。}，画面稳定收束。
段尾盒子保持打开，角色A持有发圈，角色B手停在盒边。保持同一人物和产品，拿取前后物品连续；不新增字幕、水印、台标、标题字卡或乱码，产品本身已有标识可保留。
```

学习点：先发生一件小事，由角色反应带出商品用途。对话有对象和接话关系，不能把两个人写成轮流念卖点的播音员。

## 完整示例D：直播促销，台词驱动展示动作

虚构简报：图片1定义成年女主播，图片2定义米白色软包装、绿色翻盖的100抽湿巾；用户确认活动为3包19.9元，没有其他优惠资料。13秒，热情仓库口播，场景允许文字创作。不要将此类广告改写成商品说明片。

```text
参考<图片1>定义<女主播>的面部、发型、服装与配饰，不继承图片的背景、站位和动作；参考<图片2>定义<湿巾包装>的米白色软包装、绿色翻盖、正面标签及100抽规格标识，保持包装比例、颜色与图案一致。
13秒，9:16竖屏，真人电商直播实拍风格。场景为仓库打包区，背景是蓝色货架和整齐纸箱，前方一张浅木色打包桌，明亮均匀顶光。女主播站在桌后居中，正面朝向镜头，三包湿巾叠放在桌面中央，包装正面朝前。女主播使用成年女声，音色清亮，语速中等偏快，语调热情上扬，像直播间直接向观众报活动，普通话；环境声轻微，不加抢话的音乐。
镜头1[00:00–00:04]：手持轻微晃动的中景，女主播先抬眼看向镜头，嘴角上扬，右手指向桌面的三包湿巾，左手扶住最下方一包，女主播说{姐妹们，湿巾活动来了！}；句末双手将三包湿巾一同托起至胸前，正面朝向镜头。
镜头2[00:04–00:09]：硬切固定机位中近景，起始三包湿巾已被托在胸前；左手托底，右手将上方一包微微前倾展示绿色翻盖与正面规格，眼神从包装回到镜头，眉梢轻抬，女主播说{一包一百抽，三包十九块九，}；报价格时轻点一次头，包装保持清晰，不遮住全部正面。
镜头3[00:09–00:13]：硬切固定机位中景，同一仓库背景，女主播将三包湿巾平稳放回桌面，右手向画面下方作一次简短引导后收回，面带热情微笑，女主播说{家里正好缺的，点进来看看！}；最后双手轻扶叠放湿巾两侧，闭口微笑停住。
段尾女主播站在桌后中央，三包湿巾已放稳，正面标签朝向镜头；不增减商品数量，不改变人物外观与仓库固定布局。不生成字幕、水印、台标、标题字卡、贴纸或乱码，商品包装已有文字正常保留。
```

学习点：促销台词本来就是主体。称呼、活动、规格、价格、邀请分别带动指货、托起、转包装、点头和收势。资料有明确活动才写；不另加虚构赠品和“最后一批”。
