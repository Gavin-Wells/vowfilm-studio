# H3 带货分镜 prompt 生成器（MiniMax H3 / starnet）

面向 `/v1/videos/generate` 的中文分镜 prompt。写法吸收创量类样例：素材绑定 → 场景/人物/音色 → 带时间码的音画分镜 → 段尾状态 → 约束；并修正样例常见问题（台词超载、换品残留旧话术、禁文字却又要求文字、零时长镜头塞台词等）。

誓光工程内：后端 JSON 接口只把 `prompt` 字段提交视频模型；映射与时长校验写在 `prompt` 正文内，不另附三份文档。工程默认 15 秒整条直出，`duration_seconds` 以本次输入为准（4–15 整数秒均适用同一结构）。

## 一、输入项（缺项按第四节）

- **商品**：名称、品类、外观可见特征、允许宣传的卖点/用法、活动信息（有才写）
- **参考图**：按上传顺序 `<图片1>`、`<图片2>`…，并说明每张是什么（商品图 / 人物卡 / 场景卡 / 首帧）
- **人物**：出镜人是谁（对应哪张图）、性别年龄感、着装；可多人
- **参考音频**：若有 `<音频N>` 用于谁的音色（画内口播 or 画外旁白）
- **想要的效果**：真人口播种草 / 主播促销 / 使用演示 / 双人小剧情 / 画外旁白展示 / 食品感官 等；情绪、卖点顺序、CTA（要不要、怎么说）
- **时长**：4–15 秒整数；**画幅**以 ratio 为准，缺省 9:16 竖屏
- **台词**：用户给了最终台词就逐字保留；没有则按形式创作口语台词

## 二、prompt 正文结构（固定顺序，自然段，不加「①②」或小标题）

### 素材绑定

每张实际存在的图/音各一句，只写用户真给的：

- **商品图**：参考 `<图片N>` 中的{可见特征}，将其定义为 `<商品名>`，保持瓶型、颜色、材质、标签与 Logo，不继承图中背景。
- **人物卡**：`<图片N>` 只定义 `<角色名>` 的外貌、服装、发型、体型、妆容和配饰，不采用图中背景、动作、站位或构图。
- **场景卡**：`<图片N>` 只定义 `<场景名>` 的固定空间、结构、家具和光影，不采用图中人物、动作、机位或构图。
- **首帧图**：`<图片N>` 为第 0 秒画面，继承其构图、人物姿态与商品位置。（仅用户明确说是首帧时使用）
- **音频**：参考 `<音频N>` 中的音色作为 `<角色名>` 的口播音色 / 作为画外旁白音色；音频内容不进入画面或台词。
- **角色命名**：口播类用 `<女主讲人>` / `<男主讲人>` 或 `<主播>`；剧情类用 `<角色A>` `<角色B>`。同一名称全篇不变。

### 整体设定（一段）

画幅、总时长、风格（真人写实竖屏 / 生活化好物分享 / 直播实拍 等）；场景（有场景卡就引用，没有用文字设定并保持固定）；人物起始状态：站/坐位置、朝向、双手各持什么、商品初始在哪；声音：每位发声者一句音色（性别、年龄感、质感、**语速偏快**、语调、情绪、普通话/方言）。带货口播/直播促销默认 **中等偏快到快**（约 4.5–5.5 字/秒），句间停顿短、不拖长尾音；并声明「画内口播与画外旁白为同一声音」或「旁白为独立音轨，不由出镜人物发声、不生成口型」。

### 时间轴分镜（核心）

每镜一行：

`镜头N[MM:SS-MM:SS]：切换方式+景别/构图/机位；谁在何处、以什么姿态开始，先做什么、再做什么，商品如何入画/移动/保持、标签朝向；表情、视线与台词重音如何配合；<角色名>说{台词} 或 画外<角色名>的声音说{台词} 或 旁白：{台词}；必要的动作音/环境音用 <…> 标注；本镜如何停住或切出。`

规则：

- 时间码连续、无重叠、最后一镜止于总时长；单镜一般 2–6 秒；单镜只写一个主要运镜。
- 台词写在对应镜头里，不单独列口播稿。一句话可跨镜，用「接上句」标明，不重说、不换声。
- 口播与商品特写交替：人物提出问题/吐槽 → 手部或使用特写 → 回到人物解释 → 商品陈列/收势。允许商品画面承接一段未说完的话。
- 商品细节按品类写实：洗护写喷头/按压/落点/涂抹路径；食品写色泽/纹理/夹取/入口；主播写入画时机、左右手分工、视线从商品回镜头、重音处点头或摊掌。
- 每次拿起、放下、递出都要有交代，物品不能凭空出现或消失。

### 段尾状态（一句）

收束时人物姿态、商品在谁手里/哪里、标签朝向、表情；系列片段写「作为片段结束」，不硬补 CTA。

### 约束（一句到两句）

保持 `<角色名>` 外观与 `<场景名>` 固定结构一致；不生成字幕、水印、台标、标题字卡、贴纸或乱码文字；商品包装及原生标签上的既有文字可正常保留（用户要求标签特写清晰可读时明确写出）。

## 三、台词与时长自检（写完必须在脑中校验）

- 中文口播默认按 **4.5–5.5 字/秒** 估算（紧凑促销、仓库/直播口播可到 **6 字/秒**）；慢条斯理讲解才降到 3.5–4 字/秒。每镜台词字数 ≤ 该镜秒数×5.5（快节奏镜位用 ×6）；超则删词、合并短句或略压缩动作，不要为塞词拖慢节奏。
- 时间轴里写清 **重音与换气点**，避免每镜尾留长静音；跨镜「接上句」时不停顿、不换声。
- 总时长内 CTA 最多一次，放最后一镜；用户没要 CTA 就不加。
- 保留对观众说话的关系（姐妹们 / 你们看 / 尤其是…的），情绪推进：吐槽→选择→演示→肯定，或悬念→反应→揭示；避免每镜都是「微笑、展示、很方便」。
- **换品必检**：功效、用法、部位、动作、剂型必须与当前商品一致（脱毛膏不能说「发质变顺」、洁面乳不做洗发动作）。
- 不编造未提供的价格、活动、回购经历、认证、功效数据；商品图上模糊/遮挡的文字不猜。

## 四、缺项处理

- 只缺商品或主题：在开放对话中应询问；誓光后端接口缺少必要资料时选简单可执行表达，不编造功效与价格。
- 缺场景图：文字设定固定场景，可在 prompt 首段注明「场景为文字设定」。
- 缺人物图：文字定义外观并命名，不写「参考 `<图片N>`」。
- 缺音频：文字指定音色，不写「参考 `<音频N>`」（工程未提交音频时禁止 `<音频N>`）。
- 缺时长：口播默认 12 秒，单镜演示默认 6 秒，剧情默认 15 秒；誓光电商工程以 `duration_seconds` 为准。
- 缺台词：按所选形式创作口语台词，长度符合第三节。
- 改编旧脚本：继承节奏、镜头顺序和口吻，只替换用户要求替换的人物/商品/台词，并核对语义残留。

## 五、与创量样例的对应

| 样例写法 | 生成器规则 |
|---|---|
| `参考<图片1>…定义为<商品名>` | 素材绑定 |
| `场景为室内居家…女主讲人身穿…` | 整体设定 |
| `镜头1[00:00-00:04]：中景。…女主讲人说{…}` | 时间轴分镜（补运镜、手部、标签朝向、切换方式） |
| `女主讲人音色：年轻女性…` | 声音（并声明画内/画外同声） |
| `不出现字幕、水印、台标或乱码文字` | 约束（补上「包装文字可保留」） |
| 换品后话术残留 | 换品必检 |
| 零时长镜头塞台词 | 字数/秒校验 |

## 完整示例（12 秒居家口播，教学稿）

```text
参考<图片1>中的浅蓝色按压瓶与白色刮板，将其定义为<韩植皙脱毛膏>，保持瓶型、颜色、标签与Logo一致，不继承图中背景。<图片2>只定义<女主讲人>的外貌、服装、发型、体型、妆容和配饰，不采用图中背景、动作、站位或构图。

12秒，9:16竖屏，真人写实生活化好物分享。场景为明亮居家卧室，背景是浅色墙面与一组置物架，柔和均匀日光。女主讲人身穿粉色蕾丝连衣裙，长直棕发，起始坐在画面中央面向镜头，右手持<韩植皙脱毛膏>置于腿上，左手空出，刮板放在右侧桌面。女主讲人音色：年轻女性，声音清脆，**语速偏快**，语调亲切热情、节奏紧凑，带分享欲，普通话；画内口播与画外旁白始终为同一声音。

镜头1[00:00-00:03]：固定机位中景，人物居中；女主讲人先皱一下眉看向镜头，左手在自己小臂上摆手一下，女主讲人说{夏天还在用刮刀刮腿毛的姐妹，真的别了。}。
镜头2[00:03-00:07]：硬切侧面近景，聚焦手臂与持瓶右手，面部不入画；右手将<韩植皙脱毛膏>按压两次，白色膏体落在小臂内侧，随后左手从桌面拿起刮板顺着一个方向刮过；画外女主讲人的声音说{这个抹上去一点不刺鼻，}；保留按压和刮板轻擦的动作声。
镜头3[00:07-00:10]：硬切回同一居家中景，女主讲人左手把刮板放回桌面，抬起刮过的手臂在镜头前轻抚一次，目光从手臂回到镜头，嘴角上扬，女主讲人接上句说{还有一点淡淡的香，刮完这里滑得跟没长过一样。}。
镜头4[00:10-00:12]：硬切产品中近景，右手将<韩植皙脱毛膏>竖直举至胸前，标签正面朝向镜头，居家背景轻微虚化，面部入画微笑；女主讲人说{想试的去看看。}，瓶身停稳。

段尾女主讲人坐在画面中央，右手竖直持瓶、标签朝前，左手自然垂放，闭口微笑；刮板留在桌面。

保持<女主讲人>外观与居家场景固定结构一致；不生成字幕、水印、台标、标题字卡、贴纸或乱码文字，商品包装既有文字可正常保留。
```

连续叙述式食品、双人剧情、直播促销等变体仍可按 [patterns.md](patterns.md) 做长稿拆段与宫格；**15 秒整条直出**优先使用本节时间轴结构。
