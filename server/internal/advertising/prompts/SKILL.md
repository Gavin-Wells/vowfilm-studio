# 广告视频 prompt

交付物是发给视频模型的导演指令：把广告话术、人物表演、商品画面、声音和剪辑写成一段可执行的视频。重点是还原参考广告的表达方式和制作颗粒度。

默认中文、真人写实竖屏；用户指定的文体、画幅、原文和时间要求优先。不默认调用生成或发布接口。

## 先识别输入与交付范围

从当前资料识别商品、人物/场景/首帧/分镜图、参考声音、台词、广告目的及目标时长。已有参考广告时，先提取其镜头序列、对白和口吻再写，不拿通用广告模板覆盖。

- 区分一条完整广告、其中一个片段、一个独立镜头和同稿变体。片段可以从上一句接着讲，也可以没有产品介绍或 CTA；不要每段都补一个完整销售闭环。
- 商品或主题完全缺失才先询问。其余缺项可用明确创作设定继续；不要编造未观察到的参考图、不存在的音频或真实商品参数。
- 用户只要 prompt 时，直接给可复制的完整 prompt。不默认附“商品介绍＋单独口播稿＋分镜表”三份内容。必要的素材映射和时长说明放在 prompt 外一行即可。
- 需要从零写台词时，根据所选广告形式创作自然口语，再直接融入镜头。用户给了最终台词、角色修改或剪辑顺序时，以其为准。
- 不自行查询租户数据库。技能示例使用虚构或泛化资料，不绑定历史客户的素材和标识。

## 按原文的写法选型

电商任务先读取 [references/ecommerce.md](references/ecommerce.md)：其中有样本写法的归纳、镜头语法及三种完整示例。长广告拆段、宫格、改编和批量变体再读取 [references/patterns.md](references/patterns.md)。

| 写法 | 适用内容 | prompt 组织方式 |
|---|---|---|
| 连续叙述式 | 食品、材质、使用场景蒙太奇 | 用“视频开篇、接着、随后、最后”串起具体镜头，每个画面就地接一句旁白 |
| 参考绑定＋时间轴 | 主播口播、达人种草、产品演示 | 素材职责 → 人物/产品/空间和声音 → 带时间码的音画镜头 → 段尾状态与约束 |
| 整体设定＋逐镜展开 | 情景测评、冲突反转、多人剧情 | 风格/角色/场景/情绪曲线 → 每段的主体、事件、构图、视觉重点、对白/旁白及音效 |
| SC分镜演绎 | 用户有宫格、逐镜脚本或原片时间轴 | 定义人物商品 → 画内/画外声音路由 → 按原序演绎各SC → 画面约束 |
| 单镜动作式 | 首帧动画或拆出的短镜头 | 本镜参考基准 → 主体动作与镜头变化 → 本镜台词/音效 → 约束 |

不要把所有风格压成“固定俯拍三镜头＋这是某商品＋点开看看”。需要感官画面就写微距、物体运动与声音；需要口播就写说话者表情、手势和插入镜头；需要戏剧就写冲突、反应和商品如何进入事件。

## 素材职责与开场定义

依据实际素材决定哪些字段需要写，不强制凑齐图片1、2、3：

- **人物卡**：“<图片1>只定义角色A的外貌、服装、发型、体型、妆容和配饰，不采用图中背景、动作、站位或构图。”后接有依据的具体描述。
- **商品图**：“<图片2>为目标产品外观依据，保持瓶型、颜色、材质、标签与Logo。”按图写可见细节，明确数量、正面朝向、初始在谁手中或何处。遮挡/模糊文字不猜。
- **场景卡**：写固定结构、家具、光影和空间关系，不继承图中人物。用户没有场景图时可以按简报创作场景，并说明是文字设定。
- **首帧/整镜参考**：用户要求承接构图和姿势时应继承，不能套人物卡的“忽略站位构图”。
- **参考声音**：实际存在时写“参考<音频1>中的音色生成角色A的对白/画外旁白”；没有时用文字指定音色，不虚构素材。

人物与商品的文字定义是模型的视觉约束，不等于必须让演员照念一段商品说明书。促销口播、反转故事、展示片各按其叙事承载信息。

## 每镜头把音画写在一起

参考绑定式的常用句法：

> 镜头N[起–止]：切换方式、场景、景别/构图和机位；谁在何处，以什么姿态开始，先做什么，再做什么，商品如何移动或保持；表情、视线与台词重音如何配合；角色A说{台词}／画外角色A的声音说{台词}；必要的环境音或动作音效；本镜如何停住或切出。

优先写影响画面的细节：手持位置、喷头方向、液体路径、食品纹理、人物距离、目光落点。不要堆“高级、精美、电影感”代替事件，也不要用大量无关微动作把镜头拖成慢动作。

商品演示和人物口播可交替：人物提出问题 → 手部/使用特写 → 回到人物解释 → 商品陈列。允许全片由同一声音连讲，允许产品画面承接一段未说完的话。

### 声音路由

- 画内口播：注明谁开口、谁听，口型对应本人的台词。
- 同一人物的画外旁白：人物不在画面也继续其声音；不要每次切商品特写就换成新解说员。
- 独立旁白：与角色分开定义，出镜人物不替旁白张嘴。
- 无台词动作：写明闭口、动作音和环境声，不能因为全片有旁白就给每秒填上说话。
- 一句台词可以跨同一视频任务中的多个切镜继续。标明“接上句”，不重说、不换声、不插入不必要停顿。

## 时长、连续性与文字

保持用户确认的台词、镜头数量、顺序和截断式片尾；不要为了模板整齐擅自合并重复口播镜头或补一句 CTA。只有从零创作时才自行决定句长与收束。

检查台词是否能在目标时间内自然说完，考虑音频实际读法、语速和停顿。原样本有明显超载的短镜头，不把它们当作可行速度标准。用户要求忠实复刻时保留文字稿并说明时长冲突，提供调整方案；不静默改词。

同任务镜头切换允许声音跨句；不同生成任务尽量在句子/动作完成处拆分。每个独立提交的 prompt 重复必要素材定义；连续片段写首尾持物、站位、视线和情绪，主动硬切到新场景时明确新初态。

默认不生成字幕、水印、台标、标题字卡、贴纸或乱码，商品包装和原生界面已有文字除外。用户要求字幕、分屏或其他设计时保留，不用一条“禁止所有文字/多画面”抵消指定画面。

时长、分辨率、参考数量等接口限制以当前用户资料或项目适配器为准。未核实接口时交付创作 prompt，不保证接口接受，更不保证成片效果。

## 交付前看是否像参考样本

- 有具体广告语言、具体事件和音画配合，保留所选形式的语气和节奏；没有被写成通用产品说明。
- 台词真正写入对应镜头，既没有漏掉介绍/劝说内容，也没有额外添加用户未要求的介绍段。
- 人物、商品、背景职责明确，说话者与口型一致；拿起、放下、转场不会使物体凭空消失。
- 学习样本的形式，不照搬错配内容。商品替换时核对品名、用途、剂型、动作和CTA；不新增无依据的价格、认证、健康效果或收益承诺。
- 最终输出没有多余“制作方案”挤占 prompt。用户让生成一个，就给一个写完整的；用户给了原稿，就保留其需要继承的内容。
