# 广告视频 prompt（H3）

交付物是可直接作为 `prompt` 字段提交视频模型的导演指令：把广告话术、人物表演、商品画面、声音和剪辑写成一段可执行的视频。

默认中文、真人写实竖屏；用户指定的文体、画幅、原文和 `duration_seconds` 优先。不默认调用生成或发布接口。

## 先识别输入与交付范围

从当前资料识别商品、人物/场景/首帧图、参考声音、台词、广告目的及目标时长。已有参考广告时，先提取其镜头序列、对白和口吻再写，不拿通用三镜头说明片覆盖。

- 区分一条完整广告、其中一个片段、一个独立镜头和同稿变体。
- 商品或主题完全缺失时在对话中应先询问；誓光后端 JSON 节点缺少资料时用明确设定继续，不编造未提供的参数与音频。
- 用户只要 prompt 时，只给可复制的完整 prompt 正文（结构见 [references/ecommerce.md](references/ecommerce.md)），不另附「商品介绍＋口播稿＋分镜表」三份内容。
- 用户给了最终台词、角色修改或剪辑顺序时，以其为准；从零写台词时先估时再写入对应镜头。

## H3 带货分镜（主路径）

**电商 4–15 秒任务必须先按 [references/ecommerce.md](references/ecommerce.md) 的 H3 生成器写 `prompt` 正文**：素材绑定 → 整体设定 → `镜头N[MM:SS-MM:SS]` 时间轴 → 段尾状态 → 约束；写完按该文档第三节做台词/秒自检与换品必检。

长广告拆段、宫格 SC、批量变体再读 [references/patterns.md](references/patterns.md)。

| 形式 | 组织方式 |
|---|---|
| 真人口播/种草/演示 | H3 时间轴分镜（ecommerce.md） |
| 食品蒙太奇 | 可在时间轴内写连续叙述，或 patterns 连续叙述式 |
| 双人剧情 / 直播促销 | H3 时间轴 + 角色命名与声音路由 |
| 宫格/逐镜脚本 | patterns SC 演绎 |

## 素材职责（摘要）

- **人物卡**：只定义外貌与服装，不继承背景、动作、站位、构图。
- **商品图**：外观依据，保持瓶型/颜色/标签/Logo，不继承展示背景；遮挡文字不猜。
- **场景卡**：固定空间与光影，不继承图中人物。
- **首帧**：用户要求时继承构图与姿态，不用人物卡的「忽略站位」。
- **音频**：有 `<音频N>` 才写参考音色；无则文字指定音色。

## 声音路由

- 画内口播：口型对应本人台词。
- 同一人物画外：切商品特写时声音不换人，用「画外…的声音说」或「接上句」。
- 独立旁白：与角色分开，出镜人不替旁白张嘴。
- 一句台词可跨切镜；标明接上句，不重说、不换声。

## 文字与约束

默认不生成字幕、水印、台标、标题字卡、贴纸或乱码；商品包装已有文字可保留。用户要求字幕时在对应镜头写清内容与时段。`ending_text` 为后期片尾覆盖，不在模型 prompt 重复生成。

誓光电商能力：一次视频任务直出完整时长（工程默认 15 秒），任务内自然切镜；声音来自生成任务，不拆多任务、不把声音交给后期代替。

## 交付前检查

- 时间码连续、最后一镜止于总时长，无零时长镜。
- 台词在对应镜头内，字数符合时长；**口播默认偏快（约 4.5–5.5 字/秒）**，句间停顿短；无换品语义残留。
- 人物/商品/场景职责清晰；拿放递有交代，物品不凭空消失。
- 不新增无依据的价格、认证、功效与 CTA。
