# 模板创作与 Agent 创作

工作台把两种创作方式分开：模板是已经确定的镜头结构，Agent 是从用户资料重新编排故事。

## 婚庆模板：跨越时光的誓约

首个婚庆模板参考用户提供的 76 秒横屏婚前微电影，抽取出古风初见、荷塘同游、中式誓约、复古重逢、现代相伴和当代婚礼六个叙事段落。模板重新编排成 60 秒、16:9、12 个固定镜头，每镜 5 秒。原片在选择区直接播放，并标记为“参考效果预览 · 原作者作品”；模板不会复制原片人物、字幕或音乐。

模板会保存 `templateId` 和 `templateVersion`。创建或重新编排时，后端从同一份版本化目录生成固定镜头，文本导演不会被调用；用户仍可以填写真实故事、上传人物素材和修改片尾寄语。章节之间允许换装，单个镜头内禁止变脸和变形。模板版本与镜头数量、时长、画幅不一致时，后端拒绝请求。

## Agent 创作

Agent 入口保留现有流程：用户选择场景、填写故事和拍摄要求，导演 Agent 生成导演方案、章节、造型与分镜。Agent 可以根据资料改变镜头数量和节奏，之后仍能在工作台修改单镜头或局部重做。

两种方式共用账号、素材、报价、额度冻结与视频生成基础设施；计费数量以最终后端计划为准。模板解决“先选结构再替换素材”，Agent 解决“从想法开始设计一部片子”。
