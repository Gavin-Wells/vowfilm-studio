# Vowfilm 视觉主题

当前为浅色创作工作台。大面积使用暖白和纸色，正文用深灰，仅主要操作、选中状态和少量标记使用铜橙。播放器保留深色衬底。登录、工作台、场景创建、账户、计费和管理页使用同一组变量，定义在 `app/globals.css` 的 `:root`。

| 用途 | 颜色 |
| --- | --- |
| 页面背景 | `#F7F5F1` |
| 卡片和输入框 | `#FFFFFF` |
| 主要文字 | `#25272B` |
| 辅助文字 | `#65645F` |
| 主要操作 | `#A34B2F` |
| 主按钮悬停 | `#843B24` |
| 选中底色 | `#F4E6DD` |
| 登录叙事区 | `#EAE2D5` |
| 输入框边界 | `#938B80` |
| 分隔边界 | `#DFDCD5` |

文字与主要使用背景的 WCAG 对比度计算：正文 13.74:1，辅助文字白底 5.93:1、纸色底 4.61:1，主按钮白字 5.83:1，铜橙文字选中底 4.77:1。输入框边界对白色 3.36:1。成功、处理中和错误使用独立的语义色及文字/图标，不复用品牌色表达全部状态。

保留可见键盘焦点、禁用状态、减少动态效果设置及移动端布局。创作设置直接放在「导演手记」，下拉菜单使用白底、铜橙选中态与独立浮层阴影。配色修改不改变影片素材本身。


品牌图形保存在 `public/logo-mark.svg`：深灰圆角底上的 V 字折带与播放光束，暖白和浅铜色保留小尺寸识别度。页面通过 `components/brand-logo.tsx` 统一显示图形和「誓光 / VOWFILM」字标，登录页使用较大尺寸。`public/favicon.svg` 使用同一图形，根布局显式声明网站图标。SVG 无外部字体或资源依赖；页面字标使用现有字体，并由可读文本提供名称，旁边的图形使用空 alt 避免重复朗读。
