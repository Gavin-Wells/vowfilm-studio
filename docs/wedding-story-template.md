# 把日子写成我们：婚礼故事模板

入口：新建影片 → 把日子写成我们 → 一键生成完整影片。开始前沿用系统现有报价确认；启动后自动执行文案、旁白、真实音频对齐、分镜、统一人物首帧、图生视频、配乐、混音、中文字幕和 MP4 导出，无须逐阶段点击。

原仓库： https://github.com/aaronyi97/wedding-video-guided-wizard ，固定提交 `4344397a5f9800c0a5550a83c8358f88afea9b03`。`server/internal/wedding/upstream` 保留原始中文/英文规则、采集卡、脚本和 MIT LICENSE，26 个文件按字节保留。`source.json` 记录每个文件的 SHA-256。下载原始模板会带完整源码和清单。应用的 JSON 接口与自动化适配在独立文件中，未重写原规则。

## 两种执行方式

- 一键生成：根据本次用户选择自动执行整条流程，进度、任务 ID、原图、原视频和字幕均保留。自动完成标记为 `automated`，不冒充制作方或新人确认。媒体提交使用幂等键并保存任务 ID，中断后继续查询已有任务。
- 逐步制作：仍保留原版 14 步确认方式。第 3 步记录新人文案确认，第 14 步先制作方后新人验收。修改已确认材料需要返工，原文件与旧确认留在历史中。

一键模式按用户要求省去逐步人工确认与选音等待；原始 Prompt 文件保持逐字一致，生产时仅加本系统的数据输出约定。生成结果具有随机性，文件级复刻不代表每次生成的画面逐帧相同。

## 服务依赖

使用项目已有的配置化模型服务。文案沿用当前文字模型；首帧使用当前已核对目录与文档的 `aws/gpt-image-2` 图像任务接口；视频沿用配置的视频模型并使用 `first_frame` 槽；旁白与音乐使用已核对的 `volcengine/doubao-seed-audio-1-0`。

服务端需要 FFmpeg/FFprobe、Python 3 和 `faster-whisper`。在 Go 服务使用的 Python 环境，从仓库根目录运行 `python3 -m pip install -r server/requirements-wedding.txt`。首次运行会下载 Whisper small 模型，可提前缓存。音频转录获得实际词级时间点，字幕复原原文用字；不以字数编造时长。依赖检查失败时不会启动付费生成。实际旁白过长、来源不明或音乐长度不足时明确报错，不用硬循环或伪造时间点掩盖。

生产源码：`wedding.go`（接口与人工流程）、`wedding_automatic.go`（一键编排与断点恢复）、`wedding_align.py`（真实旁白对齐）、`wedding_render.go`（完整音轨、字幕与渲染）。文案及完整分镜引用原仓库规则全文。文件下载经过所有权校验。
